# Blog Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a prerendered `/blog` section (index, post pages, RSS, git-based CMS admin) and Giscus comments to the existing Astro 6 site.

**Architecture:** Markdown posts live in `src/content/blog/` as an Astro Content Collection (glob loader + zod schema). Blog routes are prerendered (`prerender = true`) via `getStaticPaths`/`getCollection` while the rest of the site stays server-rendered. Sveltia CMS (a static `/admin` page) edits those same markdown files via GitHub; Giscus provides GitHub-Discussions comments client-side. No new actions, Durable Objects, or database.

**Tech Stack:** Astro 6 (`astro:content`, `astro/loaders`, `astro/zod`), `@astrojs/rss`, Sveltia CMS (static CDN), Giscus, Node `node:test` for pure helpers.

**Spec:** `docs/superpowers/specs/2026-10-04-blog-design.md`

## Global Constraints

- Astro 6, `output: 'server'`; blog routes opt into prerender with `export const prerender = true`.
- Content collection config lives in `src/content.config.ts`; loader is `glob` from `astro/loaders`; schema uses `z` from `astro/zod` (do NOT add a separate `zod` dependency).
- Vanilla Astro only — no React/Vue/Svelte. Scoped SCSS per component; reuse `--color-*` / `--font-*` tokens from `Layout.astro`.
- Package manager is `pnpm` only. Do not introduce npm/yarn lockfiles.
- Post URL convention has no trailing slash: `/blog/<slug>`, matching `/about` and `/contact`.
- Cover images are `z.string()` paths under `/images/...` (CMS uploads), NOT the `src/assets` image pipeline.
- Sitemap: add `/blog` to `indexablePaths`; broaden the filter to include `/blog/*`. Keep `/rss.xml` out of the sitemap.
- Draft posts (`draft: true`) are excluded from production output (`import.meta.env.PROD`).
- Prettier config in `package.json` is source of truth (4-space indent, single quotes, no semicolons, trailing commas).

## Review Focus

These are the inputs/conditions most likely to bite a reader, with the behavior a reasonable person expects. Each is pinned by a test in the owning task.

1. **Empty blog (no posts)** — `/blog` renders a friendly empty state, valid HTML, no crash; RSS still returns a valid (empty) feed.
2. **Draft posts** — never appear in the production index, post pages, sitemap, or RSS; do appear in dev.
3. **Dates sort correctly** — newest first, stable across month/year boundaries.
4. **Giscus unconfigured** — the widget renders nothing (no broken iframe, no console error), with a graceful "comments unavailable" note.
5. **Slug/href building** — `/blog/<slug>` is exact (no trailing slash, no leading `/blog//`).

- [ ] **Step 1: Install `@astrojs/rss`**

Run: `pnpm add @astrojs/rss`
Expected: dependency added to `package.json` and `pnpm-lock.yaml`.

- [ ] **Step 2: Create `src/content.config.ts`**

Register a `blog` collection using `defineCollection` from `astro:content`, the `glob` loader from `astro/loaders` (`base: './src/content/blog'`, `pattern: '**/*.md'`), and a zod schema from `astro/zod`:

```ts
import { defineCollection } from 'astro:content'
import { glob } from 'astro/loaders'
import { z } from 'astro/zod'

const blog = defineCollection({
    loader: glob({ base: './src/content/blog', pattern: '**/*.md' }),
    schema: z.object({
        title: z.string(),
        description: z.string(),
        pubDate: z.coerce.date(),
        updated: z.coerce.date().optional(),
        tags: z.array(z.string()).optional(),
        cover: z.string().optional(),
        draft: z.boolean().optional(),
    }),
})

export const collections = { blog }
```

- [ ] **Step 3: Create `src/content/blog/.gitkeep`**

Empty placeholder so the directory is tracked before any posts exist.

- [ ] **Step 4: Verify types**

Run: `pnpm astro check`
Expected: no errors (schema generates `BlogPostData` for the `blog` collection).

- [ ] **Step 5: Commit**

```bash
git add package.json pnpm-lock.yaml src/content.config.ts src/content/blog/.gitkeep
git commit -m "feat(blog): add content collection schema and rss dependency"
```

### Task 2: Pure blog helpers

**Files:**
- Create: `src/lib/blog.ts`
- Test: `src/lib/blog.test.mjs`

**Interfaces:**
- Consumes: `BlogPostData` shape from Task 1 (helpers are structural — they accept any `{ id, data }` matching that shape, so they stay free of `astro:content` imports and run under plain Node).
- Produces:
  - `type BlogPostLike = { id: string; data: BlogPostData }`
  - `postHref(id: string): string`
  - `isPublished(post: BlogPostLike, opts?: { includeDrafts?: boolean }): boolean`
  - `sortPostsByDate<T extends BlogPostLike>(posts: T[], order?: 'desc' | 'asc'): T[]`
  - `publishedPosts<T extends BlogPostLike>(posts: T[], opts?: { includeDrafts?: boolean }): T[]`
  - `formatDate(date: Date): string`

- [ ] **Step 1: Write the failing tests in `src/lib/blog.test.mjs`**

Use `node:test` + `node:assert/strict`, importing from `./blog.ts` (same pattern as `src/lib/contact/dev-bypass.test.mjs`):

- `postHref('hello-world') === '/blog/hello-world'` (no trailing slash).
- `isPublished` returns `false` for `{ data: { draft: true } }` by default, `true` with `{ includeDrafts: true }`, and `true` for non-draft posts.
- `sortPostsByDate` orders `[{pubDate: 2026-01-01}, {pubDate: 2026-06-01}, {pubDate: 2025-12-31}]` newest-first; `order: 'asc'` reverses.
- `publishedPosts` returns a sorted array excluding drafts (and includes them with `{ includeDrafts: true }`).
- `formatDate(new Date('2026-10-04T00:00:00Z')) === 'October 4, 2026'` (UTC formatter, deterministic).

- [ ] **Step 2: Run tests to verify they fail**

Run: `node --test src/lib/blog.test.mjs`
Expected: FAIL (module not found / functions undefined).

- [ ] **Step 3: Implement the helpers in `src/lib/blog.ts`**

Pure functions, no runtime imports (only `import type` if needed). `postHref` returns `'/blog/' + id`. `formatDate` uses `Intl.DateTimeFormat('en', { timeZone: 'UTC', year: 'numeric', month: 'long', day: 'numeric' })`.

- [ ] **Step 4: Run tests to verify they pass**

Run: `node --test src/lib/blog.test.mjs`
Expected: PASS (all tests green).

- [ ] **Step 5: Commit**

